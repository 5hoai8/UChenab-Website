# Typography assets

Cinzel Regular and Bold are self-hosted from Google Fonts (Cinzel v26):
- https://fonts.gstatic.com/s/cinzel/v26/8vIU7ww63mVu7gtR-kwKxNvkNOjw-tbnTYo.ttf
- https://fonts.gstatic.com/s/cinzel/v26/8vIU7ww63mVu7gtR-kwKxNvkNOjw-jHgTYo.ttf

The included Cinzel-LICENSE.txt is the SIL Open Font License from https://github.com/google/fonts/tree/main/ofl/cinzel.

Next.js optimizes/preloads these local font assets. Helvetica is requested through the system font stack (Helvetica, Helvetica Neue, Arial, sans-serif); no proprietary font binary is redistributed. On devices without Helvetica, a listed fallback is used.
